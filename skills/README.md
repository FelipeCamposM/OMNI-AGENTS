# Skills de UI/UX

Pasta para referências de design, componentes e padrões visuais do projeto PDF to Markdown.

Insira aqui arquivos de referência como:
- Tokens de cor / tipografia
- Componentes de referência (Figma exports, screenshots)
- Guias de estilo
- Inspirações de UI
- Snippets de componentes reutilizáveis

Os arquivos aqui não são importados automaticamente pelo projeto — servem como referência para o desenvolvimento da interface.
